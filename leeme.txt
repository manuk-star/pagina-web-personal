TECNOLOGÍAS UTILIZADAS

HTML5
Se utiliza para definir la estructura y el contenido del sitio.
Se emplean elementos semánticos como header, nav, main, section,
footer, figure, figcaption y address.

CSS3
Se utiliza para definir la presentación visual del sitio.
Se emplean variables CSS, Flexbox, Grid, media queries y diseño
responsive.

Flexbox y CSS Grid se utilizan para organizar y distribuir los
elementos de la interfaz. Las media queries permiten adaptar
dicha distribución a diferentes tamaños de pantalla mediante
condiciones como min-width y max-width. Por ejemplo, max-width
permite aplicar determinadas reglas hasta un ancho máximo,
mientras que min-width permite aplicarlas desde un ancho mínimo.
También pueden combinarse para definir un rango de tamaños.

JavaScript
Se utiliza para añadir interactividad al sitio.
Se emplea para controlar el menú responsive, el carrusel de la
galería y el procesamiento de la fotografía mediante Canvas.

JUSTIFICACIÓN

Se han utilizado HTML5, CSS3 y JavaScript sin frameworks ni
bibliotecas externas porque el objetivo del trabajo es utilizar
directamente las tecnologías fundamentales de la Web.

HTML5 permite crear una estructura semántica y accesible.
CSS3 permite separar la presentación del contenido, organizar los
elementos mediante Flexbox y Grid, y crear un diseño responsive.
Las media queries permiten adaptar la presentación según el
tamaño de la pantalla.
JavaScript permite implementar la interacción necesaria para
el menú, la galería y el procesamiento de imágenes.

No se utilizan bibliotecas ni frameworks adicionales.

ESTRUCTURA

El sitio está compuesto por cinco páginas HTML:

- index.html
- sobre-mi.html
- gustos.html
- galeria.html
- contacto.html

También incluye hojas de estilo CSS, código JavaScript,
fotografías, vídeo y audio.

Los recursos se mantienen dentro del propio proyecto y se utilizan
rutas relativas para facilitar su ejecución y revisión local.

CONTENIDO MULTIMEDIA

El sitio incluye:

- Fotografías personales y fotografías de viajes.
- Un vídeo relacionado con los intereses del autor.
- Un archivo de audio correspondiente a un podcast de interés.

Los elementos multimedia se incorporan mediante las etiquetas
nativas de HTML5 <img>, <video> y <audio>.
