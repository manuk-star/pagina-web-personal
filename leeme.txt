TRABAJO II — SITIO WEB PERSONAL
Manuel Ignacio Olan

1. DESCRIPCIÓN

Este proyecto consiste en un sitio web personal desarrollado como parte del Máster en Ingeniería Web.

El sitio presenta información personal, intereses, fotografías, vídeo y audio, además de una navegación entre diferentes páginas.

El diseño utiliza una estética inspirada en terminales Linux, manteniendo una estructura basada en estándares web actuales y elementos HTML semánticos.

2. ESTRUCTURA DEL PROYECTO

3. TECNOLOGÍAS UTILIZADAS

HTML5

HTML5 se utiliza para definir la estructura y el contenido del sitio web.

Se han utilizado elementos semánticos como <header>, <nav>, <main>, <section>, <article>, <footer>, <figure> y <address>, buscando que la estructura del documento represente correctamente el significado de cada contenido.

También se utilizan los elementos multimedia nativos <video> y <audio>.

CSS3

CSS3 se utiliza para definir la presentación visual del sitio.

El diseño utiliza variables CSS, Flexbox, media queries y selectores modernos.

El sitio utiliza un diseño responsive para adaptarse a diferentes tamaños de pantalla.

La estética visual está inspirada en una interfaz de terminal Linux, utilizando una combinación de colores oscuros, tipografía monoespaciada y elementos visuales similares a una consola.

JavaScript

JavaScript se utiliza para añadir interacción al sitio.

Entre sus funciones se encuentran:

* Controlar el menú de navegación en dispositivos móviles.
* Actualizar el atributo aria-expanded del menú.
* Crear el efecto de cursor parpadeante de la página principal.
* Controlar el carrusel de imágenes de la galería.
* Cambiar la imagen mostrada mediante los botones anterior y siguiente.

4. JUSTIFICACIÓN DE LAS TECNOLOGÍAS

Se decidió utilizar HTML5, CSS3 y JavaScript sin frameworks ni bibliotecas externas porque el objetivo del proyecto es desarrollar directamente las funcionalidades utilizando las tecnologías fundamentales de la Web.

HTML5 permite crear una estructura semántica y accesible.

CSS3 permite separar completamente la presentación del contenido y desarrollar un diseño responsive sin depender de frameworks externos.

JavaScript permite añadir interactividad al sitio manteniendo una implementación sencilla y adecuada para las necesidades del proyecto.

Esta elección también permite comprender de forma directa el funcionamiento de las tecnologías utilizadas en el desarrollo web.

5. FUNCIONAMIENTO

La página principal presenta la identidad del autor y utiliza JavaScript para generar un efecto de cursor parpadeante.

La sección "Sobre mí" contiene información personal y una fotografía.

La sección "Galería" contiene fotografías de diferentes viajes y utiliza JavaScript para implementar un carrusel interactivo.

La sección "Gustos" presenta diferentes intereses personales e incorpora contenido multimedia mediante elementos HTML5 de vídeo y audio.

La sección "Contacto" contiene información de contacto mediante un elemento <address>, incluyendo enlaces para teléfono y correo electrónico.

6. EJECUCIÓN Y DESPLIEGUE

El proyecto está compuesto exclusivamente por archivos HTML, CSS, JavaScript, imágenes y recursos multimedia.

Puede ejecutarse mediante un servidor web local o mediante un servidor de alojamiento web.

Para el desarrollo local se recomienda utilizar un servidor HTTP que permita acceder correctamente a todos los recursos del proyecto.

No se requieren dependencias externas ni un proceso de compilación para ejecutar el sitio.

Las rutas utilizadas para hojas de estilo, scripts, imágenes y recursos multimedia son relativas a la estructura del proyecto.

7. CONSIDERACIONES

El proyecto intenta mantener una separación clara entre estructura, presentación y comportamiento:

* HTML define la estructura y el contenido.
* CSS define la presentación visual.
* JavaScript define la interacción.

Los recursos multimedia utilizados deben mantenerse dentro de las carpetas indicadas en la estructura del proyecto para que las rutas relativas funcionen correctamente.

No se han utilizado bibliotecas ni frameworks externos.
